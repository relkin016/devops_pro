# DevOps Pro

Офлайн-учебник и тренажёр к собеседованиям по DevOps: Linux и его траблшутинг, Bash, сети, Git, Docker,
Kubernetes, Helm/GitOps, Terraform, Ansible, CI/CD, Nginx, мониторинг, базы данных и очереди, облака,
безопасность, SRE, прочие инструменты и подготовка к собеседованию.

Для каждой темы есть теория, вопросы с собеседований (junior/middle/senior), кейсы траблшутинга и квиз.
Дополнительно: тренажёр-карточки по всем вопросам, экзамен-микс и сводная страница всех поломок.
Прогресс хранится в localStorage браузера.

## Запуск

Открыть `index.html` в браузере — сервер не нужен. Или:

```bash
npm run serve        # http://localhost:8080
```

## Редактирование контента

Контент лежит в `content/*.md` (формат описан в `content/README.md`). После правок пересобрать бандл:

```bash
npm run build        # content/*.md → js/content.js
```

`js/content.js` генерируется и коммитится, чтобы приложение работало без сборки.

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | оболочка приложения |
| `css/app.css` | стили (тёмная/светлая тема, адаптив) |
| `js/app.js` | роутинг, рендер, поиск, квизы, тренажёр, прогресс |
| `js/content.js` | сгенерированный контент |
| `content/` | исходники тем в Markdown |
| `tools/build.mjs` | сборщик: Markdown → HTML, подсветка кода |
